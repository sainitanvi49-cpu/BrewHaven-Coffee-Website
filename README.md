# ☕ BrewHaven - Coffee Website

Welcome to **BrewHaven**, a coffee cafe website built using HTML, CSS, and JavaScript.

The website features a coffee-themed design with a warm color palette, an attractive layout, and interactive elements to create a pleasant user experience.

## 🌟 Features

- ☕ Attractive coffee shop design
- 🎨 Warm coffee-inspired color palette
- 📱 Responsive layout for different screen sizes
- 🧭 Smooth scrolling navigation
- 🖼️ Coffee product images
- ✨ Interactive hover animations
- 💻 Simple and user-friendly interface

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, layout, animations, and responsiveness
- **JavaScript** – Interactive functionality and smooth scrolling
